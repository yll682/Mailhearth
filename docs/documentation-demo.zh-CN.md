# 文档截图与本地演示环境操作指南

本文档介绍 Mailhearth 内置的本地文档演示环境（Documentation Demo）的使用方法、预置演示数据集以及自动化 UI 检查机制。

## 页面响应式布局与滚动特性

Mailhearth 前端针对桌面端、平板与紧凑移动端进行了完备的响应式设计：
- **纵向滚动自适应**：首次初始化向导、登录页面及系统设置页面的内容高度超过浏览器视口时，均自适应支持流畅的纵向滚动；
- **全要素可触达**：页面顶部导航、协议参数表单、操作确认与提交按钮、多语言切换选单等关键交互控件均可通过滚动完整操作，无任何遮挡或溢出截断；
- **独立局部滚动区**：管理后台工作台、导航侧边栏、邮件摘要列表、正文阅读器、资源选择导入模态弹窗以及撰写邮件浮窗均配置了独立的滚动区域，互不干扰；
- **移动端交互优化**：在窄屏或手机设备上唤起写信浮窗时，导航侧栏会自动收起折叠，收件人输入框、工具栏与发送按钮始终处于操作就绪状态。

自动化脚本 `scripts/browser-ui-check.mjs` 基于真实无头浏览器，连接本地独立的演示服务实例，覆盖 1280×720、900×360、390×844、390×320 及 320×480 等不同视口规格，全面校验域名列表、转发目标及各区域的滚动交互。

## 预置演示数据集与环境架构

本地演示环境专门用于视觉呈现、界面评估与文档截图生成，无需连接真实的外部互联网邮件服务商。

- **网络监听**：服务默认仅监听本地回环地址 `127.0.0.1:18080`；
- **数据隔离**：数据库保存在 Git 忽略目录 `data/documentation-preview/` 中，保留已创建的组织结构、管理员密码及登录会话；
- **内置邮件数据**：预置了 630 封符合 RFC 822 标准的完整 MIME 测试邮件，保存在数据库的 `documentation_demo_messages` 表中，前端通过内置的进程内 IMAP/SMTP 模拟服务进行读取与发送交互；
- **会话持久化**：每次启动时安全刷新初始演示数据，运行时产生的邮件移动、删除、星标及新邮件收发均持久保存在当前进程的独立数据库中；
- **安全保障**：所有演示数据中的 Purelymail 连接均打上明显的演示水印标识，Migadu 连接默认处于停用状态。

### 演示数据规模一览

- **12 名团队成员**：涵盖正常在职、待激活邀请、已停用以及已离职四种状态；
- **15 个邮箱**：12 个个人专属邮箱、3 个团队共享公共邮箱（包含正常活跃、暂停及归档状态）；
- **3 个服务商连接、3 个业务域名、6 种权限角色、4 个部门群组**；
- **25 个地址记录**：包含主地址、别名、邮件转发、邮件群组、前缀规则及全收兜底地址；
- **18 个发信身份、15 项共享访问授权、2 项有效邀请链接**；
- **各邮箱预置邮件**：每个邮箱均拥有 24 封收件箱邮件、5 封已发送邮件、3 封草稿、6 封归档邮件、2 封垃圾邮件及 2 封已删除邮件；
- **团队协作上下文**：共享邮箱预置 24 项成员指派记录、24 条内部私密备注及 6 项工单已解决状态标记；
- **管理操作与审计**：预置 1 项转发规则登记、6 项管理操作历史及对应的审计轨迹记录。

## 演示环境启动与截图使用

官方文档与 README 中使用的界面截图保存在 `docs/screenshots/` 目录中（详见[截图目录索引](screenshots/README.zh-CN.md)）。

### 编译与启动演示服务

在 Windows PowerShell 下执行：

```powershell
$env:GOCACHE=Join-Path (Get-Location) 'data/go-build-cache'
$env:GOTMPDIR=Join-Path (Get-Location) 'data/integration/go-work'
go build -o data/documentation-preview/documentation-demo.exe ./cmd/documentation-demo
data/documentation-preview/documentation-demo.exe
```

服务启动后，在浏览器中打开 `http://127.0.0.1:18080/`：
- **管理员账号登录**：使用已有管理员或系统预设凭据；
- **普通员工账号登录**：可使用 `bob@acme.test` 等预置成员账号，统一演示密码为：`Mailhearth-Demo-2026!`；
- **邮件阅读体验**：点击查看「Project Aurora · 合作方案与预算明细」，即可展示富文本 HTML 正文及附带的两个附件；
- **共享协同体验**：进入 `support@acme.test` 共享邮箱，即可体验团队内部备注、负责人指派及处理状态标记；
- **管理控制台**：自由查看概览、成员、邮箱、域名健康状态、群组及邮件连接管理。

### 自动化健康自检命令

演示程序自带完备的自检工具：

```powershell
data/documentation-preview/documentation-demo.exe -data-dir data/documentation-preview-check -check
```

该命令会在独立的临时目录中自动启动服务，对管理 API、邮件列表分页、正文渲染、附件下载、共享协作、资源发现、转发导入以及一次真实的本地 SMTP/IMAP 收发环回进行全流程自动化自检，确保演示数据生成逻辑 100% 可靠。
